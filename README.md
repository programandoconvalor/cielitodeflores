# 🌹 Cielito de Flores

## Catálogo Online de Arreglos Florales

Cielito de Flores es un catálogo digital diseñado para exhibir arreglos florales, ramos, diseños personalizados y diferentes opciones para regalar en momentos especiales.

Nuestra plataforma permite explorar cada producto desde cualquier dispositivo móvil, descubrir diseños, consultar precios y solicitar información o realizar pedidos directamente por WhatsApp.

El catálogo está optimizado para ofrecer una experiencia sencilla, elegante y rápida, disponible las 24 horas del día para facilitar la atención de nuestros clientes.

- Preguntas Frecuentes

# 🌹 Estructura de Productos

Cada producto incluye:

- Nombre
- SKU
- Precio
- Galería de imágenes
- Categoría
- Colección
- Descripción
- Etiquetas
- Disponibilidad

Ejemplo:

```ts
{
  id: 1,
  title: "Ramo de Rosas",
  sku: "CAT-001",
  price: 850,
  collection: "Roses Collection"
}
```
